¿QUE ES CSS?

CSS (Cascading Style Sheets) es un lenguaje de diseño utilizado para describir la presentación de un documento escrito en HTML o XML. CSS permite separar el contenido del documento de su presentación visual, lo que facilita la creación de sitios web atractivos y responsivos.

Con CSS, puedes controlar aspectos como colores, fuentes, márgenes, espaciado y disposición de los elementos en una página web. Esto permite a los desarrolladores web aplicar estilos consistentes en todo el sitio, mejorar la accesibilidad y optimizar la experiencia del usuario.
